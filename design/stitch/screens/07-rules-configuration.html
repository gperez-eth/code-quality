Path Traversal in File Operations

php:S2083 checkmarx:Path_Traversal
PHP report_problem Critical Vulnerability CWE-22 OWASP A1:2021 check_circle Active in CheckmarxPHP
725 Issues in CxPHP
info Why is this an issue?

Path manipulation occurs when an attacker can control a filesystem path argument directly via untrusted user inputs (such as $_GET, $_POST, or cookie values). By injecting relative directory traversal sequences like ../, an adversary can escape the intended root directory, reading critical system files (e.g., /etc/passwd) or initiating arbitrary remote/local file inclusions.

cancel Noncompliant Code Example PHP
// User input accepted directly without sanitation
$file = $_GET['file'];
include("templates/" . $file); // Noncompliant: Path Traversal
check_circle Compliant Solution Whitelist Strategy
// Strip malicious paths and validate against allowed list
$file = basename($_GET['file']);
$whitelist = ['home.php', 'about.php'];
if (in_array($file, $whitelist)) {
include("templates/" . $file);
}
